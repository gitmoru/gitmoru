# 0006. 브라우저 탭이 아니라 데스크톱 앱으로 만든다

## 무엇을 정했나

Electron 앱으로 만든다. 터미널에서 서버를 띄우고 브라우저로 접속하는 방식이 아니라,
아이콘을 눌러 창이 뜨는 프로그램이다.

## 왜

두 가지다.

**쓰는 사람 입장.** 사고가 났을 때 쓰는 도구다. 그 순간에 터미널을 열고 명령을 치고
포트를 확인하는 절차가 있으면 안 쓴다. 창이 바로 떠야 한다.

**격리 입장.** 브라우저 탭으로 열면 그 탭은 다른 탭들과 같은 브라우저 안에 있다.
확장 프로그램이 붙어 있고, 세션이 공유되고, 열린 포트가 남는다.
Electron 창은 그 어느 것도 아니다.

- 열린 포트가 없다. 같은 컴퓨터의 다른 프로그램이 접근할 경로 자체가 없다
- 화면은 샌드박스에서 돌고 Node 를 못 만진다
- GitHub 호출은 IPC 로 메인 프로세스에 요청한다. 토큰은 거기서 안 나온다
- 외부 주소로의 이동과 팝업을 전부 막는다

## 그래서 어떻게 되나

- 앱 번들이 커진다. 개인 도구라 감수한다
- `bin/gitmole.js` 로 브라우저 모드도 남겨둔다. 서버에서 돌려야 할 때가 있다
- 브라우저 모드에서는 세션 키와 Origin 검사가 대신 방어한다

## 하지 않기로 한 것

- 웹으로 배포하지 않는다. 누군가의 토큰이 우리 서버를 지나가게 만들지 않는다
