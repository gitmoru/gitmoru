# 0004. 토큰은 화면으로 내려가지 않는다

## 무엇을 정했나

`gh auth token` 으로 얻은 토큰은 로컬 프로세스(Electron 메인, 또는 CLI 서버) 메모리에만 둔다.
화면으로 토큰을 전달하는 경로 자체를 만들지 않는다.

## 왜

이 토큰은 조직 전체의 브랜치를 force-push 할 수 있는 권한이다.
화면에 두면 브라우저 확장, 개발자 도구, 실수로 남은 로그를 통해 새어나갈 수 있다.

그리고 우리는 바로 그 화면에 **공격자가 쓴 코드를 띄우고 있다.**
토큰과 페이로드를 같은 곳에 두지 않는다.

## 그래서 어떻게 되나

- 화면은 `/api/gh/*` 또는 IPC 로 "이 요청 좀 대신 해줘" 라고만 말한다
- 토큰을 붙이는 건 프록시다. 화면은 토큰이 있는지조차 모른다
- 로그와 에러 메시지에서 `gh[pous]_...` 모양을 마스킹한다
- 케이스 파일에도 들어가지 않는다

## 하지 않기로 한 것

- "편의를 위해" 토큰을 환경변수로 화면에 주입하지 않는다
- 토큰을 파일로 저장하지 않는다. `gh` 가 이미 관리하는 걸 두 벌로 만들지 않는다
