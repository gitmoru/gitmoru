# 0010. 도트 캐릭터를 인터페이스로 쓴다

## 무엇을 정했나

화면 한가운데에 도트로 그린 두더지 **모루**가 산다.
하늘과 땅이 있고, 저장소는 땅 위의 흙더미로 놓이고, 모루가 그 사이를 파고 다닌다.

## 왜

이 도구를 켜는 상황은 대개 좋지 않다. 새벽이고, 뭔가 잘못됐고, 무엇이 잘못됐는지 모른다.
그 상황에서 진행 막대와 표만 있는 화면은 사람을 더 조급하게 만든다.

캐릭터는 두 가지를 한다.

- **진행을 몸으로 보여준다.** 몇 % 라는 숫자보다, 모루가 오른쪽으로 파 들어가는 게 빨리 읽힌다
- **말투로 태도를 만든다.** 모루는 "안전해요" 라고 말하지 않는다.
  ADR 0002 의 원칙이 문장 단위로 지켜지는 자리가 여기다

시간대에 따라 하늘색이 바뀌는 것도 같은 이유다. 새벽에 켜면 새벽 하늘이 뜬다.
화면이 지금 시간을 같이 살고 있으면 상황이 몸으로 읽힌다.

## 그래서 어떻게 되나

- 그림은 전부 문자열 격자다 (`ui/scene/sprites.ts`). 한 줄이 한 행, `.` 은 투명
- 움직임은 CSS 로 늘였다 줄이는 게 아니라 **여러 장을 넘겨서** 만든다.
  프레임 수와 넘김 속도가 곧 성격이다
- 도트를 그리는 코드는 `ui/scene/PixelArt.tsx` 하나뿐이다
- 앱 아이콘도 같은 그림에서 굽는다 (`scripts/make-icon.ts`).
  아이콘과 화면 속 캐릭터가 다르면 같은 것이라는 게 안 읽힌다

## 하지 않기로 한 것

- 캐릭터가 판정하지 않는다. 귀엽다고 "괜찮아요" 라고 말하게 하면 ADR 0002 가 무너진다
- 도트가 아닌 요소를 섞지 않는다. 입력 칸도 우리 손으로 만든다
