# 0003. 화면은 바깥으로 요청을 못 보낸다

## 무엇을 정했나

화면(렌더러)에 CSP 를 강제해서 `connect-src 'self'` 로 묶는다.
GitHub 호출은 전부 로컬 프로세스가 대신하고, 목적지 호스트는 코드에 고정한다.

## 왜

화면에는 **공격자가 쓴 문자열이 흘러다닌다.** 파일 내용, 커밋 메시지, 브랜치 이름 전부.
그 안에는 C2 주소나 외부 엔드포인트가 들어 있다.

우리가 아무리 조심해도 언젠가 실수로 그 문자열을 `fetch` 에 넣는 코드가 들어갈 수 있다.
CSP 는 그 실수를 **코드 리뷰가 아니라 브라우저가** 막게 한다.
사람의 주의력에 기대는 방어는 언젠가 뚫린다.

## 그래서 어떻게 되나

- 프록시(`server/proxy.mjs`)가 유일한 바깥 통로다. 호스트는 `api.github.com` 으로 고정
- 쓰기는 경로 화이트리스트에 있는 것만 통과한다 (refs/heads, 브랜치 보호 조회)
- 개발 모드에서는 CSP 를 조금 푼다. `'unsafe-inline'` 과 웹소켓이 없으면 Vite 가 못 돈다.
  **하지만 `connect-src` 는 개발 모드에서도 닫아둔다.** 여기가 핵심이라서다

## 하지 않기로 한 것

- 이미지 원격 로딩을 허용하지 않는다. 이미지 URL 하나로도 신호를 보낼 수 있다
- 페이로드 안의 링크를 클릭 가능하게 만들지 않는다
