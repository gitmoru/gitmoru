# 0011. 남의 설정 파일을 우리가 고치지 않는다

## 무엇을 정했나

MCP 로 붙일 때, 다른 AI 도구의 설정 파일을 우리가 대신 편집하지 않는다.
넣을 내용과 정확한 위치를 보여주고, 적용은 사용자가 한다.

예외가 하나 있다. Claude Code 는 `claude mcp add` 라는 공식 명령이 있어서 대신 실행할 수 있다.
그 경우에도 **실행할 명령을 화면에 먼저 띄운다.**

## 왜

설정 파일은 그 사람의 작업 환경이다. 거기엔 우리가 모르는 다른 서버들이 들어 있다.
JSON 을 잘못 병합하면 그 사람의 다른 도구가 조용히 죽는다.
우리가 만든 문제인데 우리 앱에서는 아무 일도 안 일어난 것처럼 보인다.

그리고 이 앱은 "아무것도 안 바꾼다" 를 팔고 있다.
저장소는 안 바꾼다면서 사용자 홈의 설정 파일은 말없이 고치는 건 앞뒤가 안 맞는다.

## 그래서 어떻게 되나

- 도구별로 **이 컴퓨터의 실제 경로**를 계산해서 보여준다. `~/.cursor/mcp.json` 같은 축약형을 쓰지 않는다
- 그 파일이 이미 있는지 알려준다. 새로 만들지, 끼워 넣을지가 갈리기 때문이다
- 폴더를 열어주는 것까지만 한다
- 마지막 단계는 항상 "붙었는지 확인" 이다. 물어볼 문장까지 준다

## 하지 않기로 한 것

- JSON 병합 로직을 만들지 않는다. 잘 만들어도 남의 파일을 건드리는 건 그대로다
